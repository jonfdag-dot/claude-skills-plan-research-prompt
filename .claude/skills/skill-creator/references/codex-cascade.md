# Runtime scope

This starter provisions Claude only. Cross-runtime parity is explicitly N/A, and no Codex mirror skill, configuration, native catalog or agent definition is installed. A request to maintain the copied Claude skills does not imply creating another runtime.

If a future task explicitly adds another runtime, translate its discovery, invocation, tools, permission policy, models and metadata natively. Preserve portable intent, report residual differences and keep generated state, credentials and session history out of the port. A folder copy cannot establish behavioral parity.
