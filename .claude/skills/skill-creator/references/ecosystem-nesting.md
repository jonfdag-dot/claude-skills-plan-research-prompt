# Native registration in this starter

Use one `skills/<name>/SKILL.md` entrypoint at the Claude skills root. Maintain the human `skills/INDEX.md`, selected callers and actual frontmatter. Native discovery does not require the source machine's custom router, curation files, pools or hook allowlist.

Run the bundled `quick_validate.py`, check local references and review the owned diff. A static check does not prove native activation or behavior. Existing recipient organization controls continue to apply.

Default to STATIC under [verification-and-eval-admission.md](verification-and-eval-admission.md). Do not grow evaluation sets, run models or introduce a controller for ordinary authoring.
