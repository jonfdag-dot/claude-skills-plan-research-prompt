# Repository evidence and landing homes

Read the active project's instructions, current source and relevant existing plans. Locate the owning project in the plan library registry and search retained findings through the research library CLI. Do not assume the starter's examples describe the current codebase.

Classify a relevant capability as VERIFIED ACTIVE, PARTIAL, DORMANT, RESERVED, PROPOSED or UNKNOWN from inspected implementation and actual checks. A type, plan or empty field does not prove an active feature. Cite the path and observation, explain the activation cost and preserve uncertainty.

Keep generic research findings in the research library, decision-specific syntheses under its `reports/`, durable implementation plans in the owning plan-library folder and runtime facts with their canonical owner. Use one report file or one report folder with a README and supporting references. A saved report is evidence, never authority to implement or publish.
