# Native role routing

This kit supplies no native agent definitions. Use delegation only when the host environment already provides a suitable agent and the task permits it. Select any required project specialist first, confirm actual availability, and inspect its tool and model settings before dispatch.

Match tools to the assignment: research needs source access, review needs read access, and implementation needs explicitly assigned write ownership. Do not infer permissions from an agent name or invent a fallback role. Preserve the main session's selected model and existing permission controls.

Supply the bounded question, relevant skill paths, dependency results and acceptance criteria. If the selected agent cannot use the library CLI, the parent supplies retained findings and owns persistence. Workers are leaves; the parent dispatches and integrates. If no suitable agent is available, continue inline where permitted and report any required independent review that remains unavailable.
