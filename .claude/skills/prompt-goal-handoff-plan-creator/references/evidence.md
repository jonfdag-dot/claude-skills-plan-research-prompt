# Evidence

The bundle format is an adopted coordination convention, not a proven optimal handoff method. The starter omits the source installation's private reports, session archives and evidence-register identifiers. No study or model trial was rerun for this export.

The practical requirements are observable: preserve the user's actual intent and authority, keep volatile state in one file, link exact artifacts, distinguish a plan from delivered behavior and show evidence for every completion claim. `check_handoff.py` checks structural requirements; it cannot establish that the underlying work was delivered.

[Claude memory documentation](https://code.claude.com/docs/en/memory) and [native skills documentation](https://code.claude.com/docs/en/skills) describe runtime mechanisms. They do not prove this bundle format optimal, guarantee lossless compaction or authorize scanning private transcripts. Use current native documentation for a version-specific behavior question.

Original-source claims in copied references remain scoped to their stated source and date. Do not repeat an empirical effect size without inspecting its original study and qualifications. This generic handoff contract relies on explicit requirements and actual acceptance evidence rather than imported private evidence IDs.

Automatic prompt logging, scheduled handoffs, self-triggered session closure, extra evaluation campaigns and new task controllers are outside this workflow. A requested handoff uses current-session messages and authorized user-supplied originals; missing context stays explicit.
