# Decision-specific reports

For each research task, create one Markdown report file or one report folder here. A multi-file folder uses README.md for the synthesis and references/ for its supporting material. Cite canonical R-IDs and original sources next to the claims they support. Preserve consequential unknowns, rejected options and contradictions.

Use `scripts/templates/report.md.template` as an outline, keeping only sections the decision needs. A report never replaces canonical source records or grants execution/publication authority. Durable plans live in the plan library.
