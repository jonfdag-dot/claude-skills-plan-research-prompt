# Navigate evidence notes

Read the root README and selected domain README before searching that folder. Use the CLI to learn labels, find a bounded pool and show exact IDs. Open up to 3–5 closest sections; one exact match can suffice. Narrow noisy searches and expand only for a remaining question or contradiction.

Read Claim and Use when first, then scope, status, basis, access, Checked and Recheck. Follow Canonical owner for detail and Replacement for a superseded finding. A batch file or index is not a command to load the entire corpus.

If retrieval is weak, try an alias, adjacent domain, exact source identity and one bounded wider search before reporting a gap. Carry selected IDs through follow-ups unless scope or evidence changes. New domain folders need a README before their first finding; the CLI builds the index when adding a record.

Keep one canonical section per scoped claim. Update sources and pointers through research.py rather than duplicating evidence; validate once after the reconciled write batch.
