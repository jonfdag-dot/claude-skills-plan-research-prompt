# Plan library index

| File | Read or change when |
| --- | --- |
| [CLAUDE.md](CLAUDE.md) | Starting library work; short storage, authority and lifecycle rules. |
| [AGENTS.md](AGENTS.md) | Optional identical portable-policy copy for another coding tool; no other runtime is configured. |
| [README.md](README.md) | Registering a project, writing a plan, indexing or archiving it. |
| [projects.md](projects.md) | Finding the owning project folder. |
| [projects.json](projects.json) | Changing machine-readable ownership and source-root configuration. |
| [starter-example/ROLES.md](starter-example/ROLES.md) | Seeing the six-column role index and its example reference row. |
| [starter-example/2026-10-27-example-plan.md](starter-example/2026-10-27-example-plan.md) | Seeing a plan with honest unrun acceptance and dated state. |
| [scripts/templates/plan.md.template](scripts/templates/plan.md.template) | Copying a new single-file plan. |
| [scripts/templates/project-CLAUDE.md.template](scripts/templates/project-CLAUDE.md.template) | Adding library routing to an active source repository. |
| [scripts/roles.py](scripts/roles.py) | Reading a bounded role page or resolving a stable role to a main file. |
| [scripts/validate.py](scripts/validate.py) | Checking lifecycle, placement, role and successor structure. |
| tests/ | Regression checks for the two scripts; fixture content is synthetic. |

There is one maintained ROLES index per registered project. This file is a map of the library format, not a duplicate task-status ledger.
